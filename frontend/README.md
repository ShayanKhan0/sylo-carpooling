# Sylo - Smart Carpooling App

A professional Flutter application with a bright, modern UI inspired by leading ride-hailing apps.

## Features

- ✨ Animated splash screen
- 🎨 Bright navy blue & white color scheme
- 🔐 Authentication flow
- 📱 Modern, professional UI

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run the app
flutter run
```

## Color Scheme

- **Primary**: Navy Blue (#1A237E)
- **Secondary**: Bright Blue (#2196F3)
- **Accent**: Vibrant Cyan (#00BCD4)
- **Background**: Pure White (#FFFFFF)
- **Text**: Dark Grey (#212121)
